The Framework

Six Phases. One Connected System.

Every gap caught at requirements costs minutes to fix. The same gap caught in production costs months — per incident, indefinitely.

Phase 01 · Requirements
Requirements
SRD

Failure modes, observability requirements, and customer impact classified before design begins. Support signs off before a line of code is scoped.

Phase 02 · Design
Architecture Review
SAR

Every failure point and blind spot mapped in the architecture before build. Every gap gets a priority and a plan.

Phase 03 · Build
Implementation Checklist
SIC

Attaches to every PR. Logging, error handling, four golden signals, failure mode tests. A PR cannot merge without it.

Phase 04 · Test
Supportability Test Plan
STP

Validates that a support engineer can diagnose every failure mode independently before any feature ships.

Phase 05 · Release
Readiness Review
SRR

The final gate. Support lead and engineering lead both sign. Release does not proceed without both signatures.

Phase 06 · Operate
Feedback Loop
SFL

Every incident makes the next one cheaper. Operational experience flows back into the next design cycle automatically.
